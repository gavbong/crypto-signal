## Session Goal

Investigate and fix the `liquidity_grab` strategy, which lost significant PnL on 2026-05-17 (-150+ USDT in one evening). Then calibrate slippage estimates against real market data and add per-strategy RR ratios to compensate for different cost structures.

## What Caused the 2026-05-17 Losses

Three correlated `liquidity_grab` longs fired within 35 minutes on the same dump:

| Time (UTC) | Pair | Regime Confidence | Outcome |
|-----------|------|------------------|---------|
| 23:34 | SOL/USDT | choppy, conf=0.213 | SL at 23:49 |
| 23:34 | ETH/USDT | choppy, conf=0.393 | SL at 23:49 |  
| 23:38 | BTC/USDT | choppy, conf=0.279 | SL at 23:49 |

Root causes:
1. **Low regime confidence** — backtest shows choppy <0.30 WR=40.8%, avg_r=-0.078. SOL conf=0.213 and BTC conf=0.279 were below the profitable threshold.
2. **Correlated positions** — BTC/ETH/SOL move together; stacking three longs = triple loss on a single macro move.
3. **Swing window too narrow** — 20 candles (5h) doesn't capture meaningful liquidity levels. Real institutional stops cluster at daily/weekly highs/lows.
4. **Slippage model badly miscalibrated** — paper trader assumed 0.05% SL exit slippage; real liquidity_grab SL gap averaged 1.41% (28× too low). The strategy's net PnL was worse than the model showed.

## Changes Deployed This Session

### 1. `signals/generator.py` — liquidity_grab overhaul

**Confidence gates (most impactful change):**
```python
# Derived from backtest (n=1496 choppy, n=878 high-vol):
if regime.label == "choppy" and regime.confidence < 0.30:
    return None  # WR=40.8%, avg_r=-0.078 — persistent loser
if regime.label == "high-volatility" and regime.confidence >= 0.50:
    return None  # WR=43.7%, avg_r=-0.245 — trending move, not reversal
```

**Swing window: 20 → 30 candles** (5h → 7.5h at 15min):
```python
swing_window = prior.iloc[-30:]  # was -20
```

**Reversal threshold: 0.2 → 0.25 ATR** (filters weak rejections):
```python
# long: close must recover 0.25 ATR above sweep low (was 0.2)
# short: close must fall 0.25 ATR below sweep high (was 0.2)
```

**Per-strategy RR in `_calc_take_profit()`:**
```python
strategy_rr = c.get("rr_ratio_strategy", {})
if strategy and strategy in strategy_rr:
    rr = strategy_rr[strategy]  # overrides regime-level RR
```
And `_signal()` updated to pass `strategy` to `_calc_take_profit`.

### 4. `scripts/slippage_calibration.py` — new calibration script

Measures real vs estimated slippage by fetching OHLCV from MEXC via ccxt:
- **Entry:** signal candle close → next candle open adverse move
- **Exit:** SL price vs candle low/high on the stop-triggered candle

Calibration results (n=15):
```
Entry slippage: adverse mean=0.135%, median=0.037%
SL exit slippage: mean=0.730%, median=0.414% (max 2.23%)
liquidity_grab SL gap specifically: mean=1.41%, median=1.22%
```
